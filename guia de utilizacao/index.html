>_ ./omnigraph.sh

Transforme qualquer projeto num mapa que você consulta em vez de abrir arquivo por arquivo.

O OmniGraph lê o seu código, documentos e PDFs e monta um mapa visual de tudo — o que existe, o que se conecta com o quê. Roda no seu computador, com uma IA local que não gasta tokens de API.

1Comece aqui

Três passos. Sem terminal, sem configuração.

1

Instale com um comando

O jeito recomendado — não precisa baixar ZIP, não pega o bloqueio do macOS. Cole uma linha no terminal e ele baixa e instala tudo (a ferramenta, a IA local e o modelo). Na primeira vez pode demorar (baixa alguns GB da IA).

🍎 macOS  /  🐧 Linux — cole no Terminal:

Terminal
$ curl -fsSL https://raw.githubusercontent.com/Zespek/OmniGraph/main/instalar.sh | bash

🪟 Windows — cole no PowerShell:

PowerShell
> powershell -c "irm https://raw.githubusercontent.com/Zespek/OmniGraph/main/instalar.ps1 | iex"

Baixou o ZIP e quer o duplo-clique? O macOS bloqueia scripts baixados — é a segurança do sistema, não erro do instalador. Prefira o comando acima. Se insistir no ZIP, no Terminal, dentro da pasta:

Terminal (pasta do OmniGraph, só para ZIP)
$ xattr -dr com.apple.quarantine . && bash "Instalar OmniGraph.command"
2

Aponte para o seu projeto

Abra o Terminal na pasta do projeto que você quer mapear e rode este comando (são dois passos numa linha só: extrai os dados e depois desenha o gráfico):

terminal
$ omnigraph extract . && omnigraph cluster-only .

Pronto — o gráfico é gerado em omnigraph-out/graph.html.

Não apareceu o graph.html? O extract sozinho só cria os dados; é o cluster-only que desenha o gráfico. Rode omnigraph cluster-only . na pasta do projeto.

Deu command not found? Feche o terminal e abra um novo — o comando só entra no PATH em terminais abertos depois da instalação.

3

Explore o mapa

Abra o arquivo omnigraph-out/graph.html no navegador e navegue clicando. Ou faça perguntas direto no terminal (próxima seção).

🔒 A IA roda no seu computador

O OmniGraph já vem com o Ollama e um modelo de IA que roda 100% local. Nada é enviado para a nuvem e você não paga tokens de API. O instalador cuida disso — você não precisa configurar nada.

local · privado · sem custo por uso

2Perguntas ao mapa

Em vez de procurar nos arquivos, pergunte.

terminal
# qual o caminho entre duas coisas do projeto
$ omnigraph path "Login" "Banco de Dados"

# explicar o que uma parte faz, em linguagem simples
$ omnigraph explain "Pagamento"

# atualizar o mapa depois de mexer no codigo (rapido, sem IA)
$ omnigraph update .
extract .Lê o projeto e extrai os dados do mapa (gera graph.json)
cluster-only .Desenha o gráfico visual (graph.html) e o relatório
update .Atualiza o mapa depois de você mexer no código
path "A" "B"Mostra como duas partes se ligam
explain "X"Explica uma parte em português claro

3Manter atualizado

Sempre que quiser, dê de novo um duplo-clique em Instalar OmniGraph.command. Ele verifica se há uma versão nova, atualiza o que precisar e não baixa de novo o que já está pronto. Pode rodar quantas vezes quiser — é seguro.

4Para quem quer mais

Opcional — o básico acima já resolve o dia a dia.

Usar com um assistente de IA (Claude, Cursor…)

O comando omnigraph install registra o OmniGraph no seu assistente, que passa a consultar o mapa sozinho quando você pergunta sobre o projeto. O servidor que faz essa ponte é o omnigraph-mcp (sobe automático).

Servir o mapa para vários computadores

Para uma equipe consultar o mesmo mapa, suba o servidor em rede:

terminal
$ omnigraph-mcp graph.json --transport http --host 0.0.0.0 --port 8080

Exposto na rede? Proteja com uma chave: --api-key (ou a variável OMNIGRAPH_API_KEY).

Preferir uma IA da nuvem? Se você tiver uma chave de API (OpenAI, Anthropic…) configurada, o OmniGraph a usa no lugar do Ollama. Sem chave, ele usa a IA local — o padrão, sem custo.
